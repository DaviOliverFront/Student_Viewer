# 🎓 Student Viewer

**Status:** 🚧 Prototype — visual design finalized, functionality still in progress

Student Viewer is a web platform designed to simplify how teachers manage students, grades, attendance, and communication in the classroom. This repository currently contains the **visual prototype** of the project: the interface, layout, and navigation structure are complete and represent the intended final look and feel, but the underlying logic (authentication, database, CRUD operations, etc.) is not yet implemented.

## 📌 About the project

Teachers often juggle multiple spreadsheets, notebooks, and apps just to keep track of their students' grades, attendance, and important reminders. Student Viewer aims to bring all of that into a single, simple dashboard.

**For teachers 🧑‍🏫**, the platform provides:
- 👥 A centralized panel to manage students and classes
- 📝 A straightforward way to register and edit grades
- 📋 Attendance and activity tracking per class
- 🔔 A reminder system to notify students about assignments, exams, and important dates

**For students 🧑‍🎓**, the platform will offer:
- 📊 Quick access to their grades and class information
- ✅ Visibility into attendance records
- 📩 Reminders and notices sent directly by their teachers

The goal is to reduce administrative overhead for teachers while giving students a clearer, more organized view of their academic progress.

## 🖥️ Current state

This version is a **UI prototype**. It demonstrates:
- 🧭 The main dashboard layout, including sidebar navigation
- 🗂️ The four core feature areas (Student Management, Grades, Class Management, Reminders)
- 🎨 The overall visual identity (colors, typography, spacing)

**Not yet implemented ⚠️:**
- 🗄️ Backend and database integration
- 🔐 Authentication and user roles (teacher vs. student)
- ⚙️ Functional CRUD for students, grades, classes, and reminders
- 🧪 Data validation and error handling

## 🛠️ Tech stack

- **HTML5** — page structure
- **CSS3** — custom styling and visual identity
- **Bootstrap 5** (via CDN) — responsive grid, layout utilities, and base components
